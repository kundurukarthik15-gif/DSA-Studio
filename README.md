# DSA Studio

DSA Studio is an interactive learning platform designed to help B.Tech students understand Data Structures and Algorithms through visualizations and step-by-step execution.

## Planned Features

- Visualize data structures such as arrays, stacks, queues, linked lists, trees, and graphs.
- Understand algorithms through step-by-step animations.
- Visualize loops, conditional statements, and break/continue statements.
- Track algorithm execution and understand how data changes.
- Learn time and space complexity.
